# Jax Coach 0.4.0 — comece aqui

Esta versão adiciona o **Acompanhamento seguro** no Modo Foco. Você liga e desliga quando quiser; enquanto estiver ligado, o app lê um resumo do League Client local a cada 10 segundos e mostra fatos da partida junto de opções históricas de treino.

Baixe e abra **Jax-Coach-0.4.0-x64-setup.exe**. Feche uma versão antiga antes de instalar.

Para testar sem LoL, abra o app e use a Demonstração. Para usar o acompanhamento:

1. Abra League of Legends e entre na partida.
2. Abra o Jax Coach e clique em **Painel de foco**.
3. Arraste a janela para o segundo monitor.
4. Clique em **Ativar** em **Acompanhamento seguro**.
5. Quando quiser parar, clique em **Desligar**.

O painel pode mostrar modo/tempo, seu campeão, nível, rota, itens, placar e o adversário da mesma rota quando o League Client informar. Abaixo aparecem algumas alternativas históricas de treino para você escolher. O app não aperta teclas, não mexe no mouse, não lê memória e não envia dados da partida para IA.

Se o League Client ainda não estiver respondendo, o painel explica isso e continua mostrando seu objetivo histórico. O acompanhamento só funciona no aplicativo desktop; no navegador a Demonstração continua disponível.

Para puxar partidas encerradas, use **Configurações → Testar conexão** e depois **Sincronizar minhas partidas** com uma chave válida. Não envie sua chave pelo chat. Ela não é salva no código, no Git ou no banco.

Para consultar dados completos do League Client, use **Diagnóstico → Dados locais da partida → Consultar dados locais agora**. Essa consulta é manual e separada do acompanhamento seguro.
